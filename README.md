# Custom Log4j2 appender for sending logs to Apache Kafka with structured JSON formatting.

-  KafkaAppender - Custom Log4j2 appender for Apache Kafka
-  JsonLayout - Structured JSON logging with configurable fields
- Thread-safe - Managed Kafka producer lifecycle
- Plugin-based - Works with Log4j2 plugin system
- Flexible configuration - XML or programmatic setup
- Structured logging - Support for MapMessage and ThreadContext (MDC)
- Integration tests - Full test suite with Testcontainers
- Example application - Ready-to-use sample
